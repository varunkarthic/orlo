# Decisions

| Date | Decision | Why | Source / licence |
|---|---|---|---|
| 2026-10-18 | npm workspaces, not pnpm | `pnpm`/`corepack` unavailable in the authoring environment; npm works on Read the Docs without extra setup | n/a |
| 2026-10-18 | Motion for React (`motion`) as the animation engine | Springs, presence, layout, `MotionConfig` reduced-motion | MIT, https://motion.dev/docs/react |
| 2026-10-18 | Base UI as the planned headless foundation for overlays/tabs/switch | Accessible unstyled primitives; one library rather than Radix + Base UI | MIT, https://base-ui.com |
| 2026-10-18 | Tokens in TypeScript, CSS generated by Node's native type stripping | No extra build tool; single source for CSS and JS | n/a |
| 2026-10-18 | Docs prerendered to one HTML file per route, relative asset paths | Read the Docs serves static files under `/en/<version>/`; no SPA rewrite available | https://docs.readthedocs.com/platform/stable/build-customization.html |
| 2026-10-18 | Wordmark direction B ("finishing edge") chosen | Open-rim O is the only embellishment; reads at 16px and in one colour. A (typographic continuity) and C (organic rhythm) not pursued yet | original artwork |
| 2026-10-18 | Accent `#A8370A` (persimmon) on warm off-white/graphite | Distinct from blue/purple defaults; contrast tested | original |
| 2026-10-18 | Licence: MIT | Conventional permissive default; **maintainer to confirm** | n/a |

Motion values are initial design hypotheses, not Apple or Google values. Numeric spring tokens were not read from vendor pages.
Italian *orlo* = edge/hem: Cambridge Dictionary (Italian–English) https://dictionary.cambridge.org/dictionary/italian-english/orlo (cited from the brief; to be re-verified before release).
