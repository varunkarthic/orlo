# Project status

Orlo is a beta, pre-release React design framework. The current generated catalogue lists 131 components and the docs build produces 698 static routes. These counts describe scope, not readiness.

The current architecture, evidence, completed slices, and outstanding master-prompt work are recorded in the [implementation ledger](IMPLEMENTATION_LEDGER.md). That ledger distinguishes local checks from hosted CI and work that has not yet been verified. The normative interaction and token requirements remain in [Orlo design rules](../ORLO_DESIGN_RULES.md).

No component should be described as accessible, production-ready, or stable solely because a test or automated axe scan passed. Manual screen-reader, device, cross-browser, and exported-code review are still needed.
